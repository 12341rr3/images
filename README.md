Indian Railway Data Analysis Dashboard (Power BI).
This project analyzes Indian Railway dataset from Kaggle to extract insights on passenger trends, revenue, and route performance using Power BI.
Tools Used: Power BI,Power Query,DAX,Excel.
Key Insights:-Identified busiest railway routes and peak travel periods,Analyzed revenue trends and passenger distribution,Compared train performance across regions.
Dataset:-Source: Kaggle (Indian Railway Dataset)
